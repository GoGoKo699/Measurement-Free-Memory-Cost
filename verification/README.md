# Reproduce the finite checks

The scientific conclusions are analytical. These deterministic calculations check the finite identities and constructions most vulnerable to a sign, support, scheduling, or resource-count error.

## Environment and command

The checked environment is Python 3.12.14 with NumPy 2.3.5 and SciPy 1.17.0. The archive checker uses only the standard library; the two matrix checkers use NumPy. The score-transfer checker uses SciPy for an independently solved linear program.

From the repository root:

```bash
python3 -m pip install -r verification/requirements.txt
python3 verification/run_all.py
python3 verification/check_learning.py
```

The runner executes all seven scientific checks and compares their JSON outputs with the committed files in [expected/](expected/). Integer counts, rational strings, structure, and assertions must agree. Floating reference values use absolute and relative comparison tolerances of `1e-9`; each program also asserts its mathematical checks directly. The independent numerical injection LP uses relative tolerance `1e-7` internally; the spectral probability LP uses absolute tolerance `1e-10`. Both are separate from exact rational certificates. Runtime version strings are reported by the algebra checker but excluded from result comparison.

The reference outputs are not regenerated by the verification command. A failing identity or comparison exits unsuccessfully. The successful runner ends with a JSON object whose status is `PASS` and whose seven checks also report `PASS`.

The two-qubit algebra checker uses dense matrices rather than the symbolic rank-contraction proof. Its scalar optimization checks use exact fractions and matched primal/dual certificates, including coasting equality and dimension-cap failure cases.

The archive checker includes examples where correcting only the final syndrome fails while using successive syndrome differences succeeds. Its tree checks include the initial replica noise, and its workspace allocation requires old parents and new targets to coexist.

The five-qubit checker reconstructs a decoder from the stabilizers and logical operators. It then evaluates the explicit correction circuit on every Pauli error, rather than checking only the polynomial syntax. The bad-error counts by weight are

```text
[0, 0, 90, 210, 270, 198]
```

for weights zero through five. In particular all weight-zero and weight-one errors are corrected. The six quadratic controlled corrections use exact seven-T decompositions from the cited primary circuit literature; the verification does not claim a minimum possible T count.

## Run one calculation

```bash
python3 verification/verify_pauli_algebra.py
python3 verification/verify_archive.py
python3 verification/verify_five_qubit.py
python3 verification/verify_guessing_processing.py
python3 verification/verify_moment_processing.py
python3 verification/verify_guessing_decay.py
python3 verification/verify_tanner_memory.py
```

Each prints a JSON report. The Pauli-algebra, archive and guessing-processing programs additionally accept an optional `--output PATH` argument. An output written by a new run is evidence for that run, not a replacement for the corresponding proof.

## Delayed-basis score and learning checks

[Guessing and processing](../science/guessing_processing.md) proves the CPTP quantum-plus-classical factorization and all-cut score floor, then applies the existing gate and contiguous-interval ledger. The finite checker keeps the classical-alphabet dimension bound separate from the additional mathematical refinement labels used inside the guessing proof. It compares the direct branch bound with the specified prior recovery family, including the coherent-block bottleneck. Exact certificates establish that prior recovery reproduces both convenient all-cut floors at every challenge size; stronger integer-algebra optimizations remain a separate comparison. The six canonical two-qubit factorization classes and basis-dependent endpoint probabilities are checked independently in [Lattice Memory Certification's interface checker](https://github.com/GoGoKo699/Lattice-Memory-Certification/blob/main/verification/verify_noisy_processing.py).

The injection LP comparison supplements the exact primal/dual certificates already checked by the algebra program. The spectral LP independently maximizes the BB84 coefficients over normalized probabilities bounded by the recovery fidelity. It tests that retaining this normalization gives the stated finite threshold formula; the quantum derivation comes from the cited spectral proof. Neither finite comparison establishes the optimal attainable score curve or verifies a device's depolarizing-noise, controller or side-channel premises.

[check_learning.py](check_learning.py) verifies M01–M30, their backward dependencies, the selected Watrous (2018) bridge and local destinations including heading fragments. It does not assess a reader or verify hosted mathematical rendering. Run it with `--output /tmp/memory-cost-learning.json` to retain a fresh report; [learning_results.json](learning_results.json) records the inspected source's output.

## Resource-comparison plot

The [plot generator](Graph/generate_plots.py) evaluates the explicit finite
resource certificates for `k=1`, `gamma=0.01`, `epsilon=0.01`, and all integer
durations `D=1..1000`. It compares the necessary zero-T width, the sufficient
noisy-archive width, and coherent recovery's width and internal T budget. The
code retains the same fidelity, noise, and register-accounting conventions as
the scientific chapters.

From the repository root, install the pinned plotting dependencies and check
both the values and the rendered vector asset:

```bash
python3 -m pip install -r verification/Graph/requirements.txt
python3 verification/Graph/generate_plots.py --check
```

The checked plotting environment uses Python 3.12.14, NumPy 2.3.5, and
Matplotlib 3.10.8. The command regenerates in a temporary directory and compares
the PDF and CSV byte for byte with the committed [reference plot](Graph/expected/resource_comparison.pdf)
and [numerical rows](Graph/expected/resource_comparison.csv). It also compares
all analytical fields of the [finite certificate](Graph/expected/resource_comparison.json),
including the parameters and error bounds. Python and dependency versions are
reported separately as runtime provenance, together with literal metadata
hashes. A provenance difference is reported without treating it as a numerical
failure when the PDF, CSV, and analytical fields match. Add
`--strict-provenance` to require the original version records as well.
Committed references are never regenerated by this command, and an analytical
or plot discrepancy exits unsuccessfully.

To retain fresh output, run the generator without `--check`:

```bash
python3 verification/Graph/generate_plots.py
```

The default destinations are
`verification/Graph/generated/Graph/resource_comparison.pdf` and
`verification/Graph/generated/data/`. The optional `--output-dir` and
`--data-dir` flags select other destinations, including with `--check`; paths
inside the committed `expected/` directory are rejected.

Every plotted point checks both constructions' half-diamond error certificates,
the archive's simultaneous parent/child register count, and consistency between
the necessary and sufficient resource bounds. At `D=1000`, coherent recovery
has `n=125`, at most `260400` internal T/T-dagger gates, and error certificate
approximately `0.0078213`. The curves retain the remaining gap between necessity
and explicit constructions; they do not identify an optimal frontier.

## Proof boundaries

The [Pauli-envelope proof](../science/pauli_envelopes.md) establishes dimension-independent contraction and reference-stable forgetting. [Control cost](../science/control_cost.md) proves the quantum-channel rank floor and finite-depth budgets. [Clifford quantum lifetime](../science/clifford_lifetime.md) proves the unbounded syndrome-tree construction, and [Coherent recovery](../science/coherent_recovery.md) proves concatenation and batching for arbitrary parameters in its stated range.

Small-system matrix identities do not certify all possible channels or circuit sizes. Finite tree enumeration does not prove arbitrary-depth reconstruction. Exactness of the continuous scalar injection relaxation does not imply a physical circuit attains the optimal T count. The written induction, conditioning, and resource-accounting arguments supply those distinctions.

No sampled hardware threshold or noisy-gate implementation is inferred from this suite. The constructions retain ideal global control between the specified noise layers.



## Exponential-moment processing checks

Run `python verification/verify_moment_processing.py`, or use `python verification/run_all.py` to compare all seven scientific suites with their committed expected outputs. The moment suite checks the pivot/noise inequality on all subspaces at widths one through three, reset and T updates, the 169 exact integer-algebra witnesses for the combined finite polygon, rational logarithm enclosures for the 244/58 counts, and the specified recovery-family comparison. All bound and rounding decisions use exact integer or rational arithmetic. These checks supplement the general proof in [Moment processing](../science/moment_processing.md); they do not establish physical feasibility or optimal T cost.

## Tanner compilation and explicit guessing decay

`verify_tanner_memory.py` checks all 1,024 clean-input cases of every two-input/two-output Boolean lookup, an entire nonlinear correction Choi channel with a reference and reset scratch, exact resource/invariant margins, bounded code-length ratios, and a sufficient-size scalar fixture. The fixture does not instantiate an admissible Tanner block. The construction theorem depends on the inherited good-code/parallel-decoder results and the written fixed-circuit proof in [Tanner memory](../science/tanner_memory.md).

`verify_guessing_decay.py` checks exact scalar ledger inversion, rational interval certificates for the global one-variable exponent optimization and finite score bounds. It also forms certified full integer-algebra and specified recovery-family moment profiles before branch averaging. The universal quantifiers and limiting statement are proved in [Guessing decay](../science/guessing_decay.md); no finite computation establishes a processing capacity. Both scripts are included in `run_all.py`, with committed deterministic expected JSON.
