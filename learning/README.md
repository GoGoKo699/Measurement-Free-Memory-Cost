# Learning guide

**Question:** what processing must a noisy device perform while it is retaining unknown quantum information?

The single educational anchor is **John Watrous, *The Theory of Quantum Information* (2018)**, shared with [Lattice Memory Certification](https://github.com/GoGoKo699/Lattice-Memory-Certification). Start with the [Watrous bridge](WATROUS_BRIDGE.md) for selected sections, notation and a complete two-qubit algebra example. It separates textbook foundations from the project's Pauli-envelope argument, code constructions and inherited uncertainty/recovery results.

For a continuous account of the memory model and constructions, read the [explanatory report (PDF)](report/Measurement_Free_Memory_Cost_Report.pdf). The [guessing-score chapter](../science/guessing_processing.md) gives the delayed-basis application and its recovery comparison.

The [30-milestone map](MILESTONES.md) has 12 background/preliminary targets and 18 narrative/innovation targets. M01–M12 assemble states, channels, noise, controls, records and endpoints into the exact model. M13–M23 develop the envelope, bottleneck and continuing-processing ledger. M24–M30 compare constructions, introduce the score-based premise and synthesize the resource frontier. Each target gives its question, dependencies, conceptual connection and scientific sources.

For a specialist route, read the [model](../science/model.md), [Pauli envelopes](../science/pauli_envelopes.md) and [control cost](../science/control_cost.md), then compare [Clifford-only storage](../science/clifford_lifetime.md) with [coherent recovery](../science/coherent_recovery.md). The [score transfer](../science/guessing_processing.md) uses the same full-output envelope and budget rather than changing the storage model.

The route ends with the ability to distinguish physical width, noisy time and charged processing; explain why a free final decoder does not eliminate interior interval constraints; and identify which assumptions a guessing score does and does not test. The map expresses common scientific understanding targets, not any reader's progress or assessment history.
